Дерево проверок

По этому дереву сервис принимает решение. Каждая проверка смотрит на признаки, которые модели извлекают из кадров (люди, предметы на столе, сейф, экран ноутбука, дверь). Видео получает вердикт «нарушение», если сработала хотя бы одна включённая проверка; вложенные проверки работают, только если включён и сработал родитель. Изменения применяются к следующим анализам — для уже загруженных видео нажмите «Перезапустить анализ».

Общие параметры

person_min_y — нижний край рамки человека (доля высоты кадра), ниже которого человек считается у стола; отсекает людей за стеклом. Для другой камеры его стоит проверить в первую очередь. person_conf — минимальная уверенность детектора людей.
